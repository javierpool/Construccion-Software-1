# Repositorio de Evidencias - Construcción de Software I

## Descripción del Proyecto
Este repositorio tiene como objetivo organizar, gestionar y realizar el seguimiento de los entregables correspondientes a las tres unidades del curso de Construcción de Software I[cite: 19].

**Proyecto Integrador:** Aplicación móvil para la mejora de la efectividad en el reporte de incidencias ciudadanas en Tacna, 2026[cite: 19].

## Organización de las Unidades

### UNIDAD 01
Contiene la estructura base, los documentos de planificación y el diseño inicial del proyecto, organizados por semanas:
* **Semana 01:** Planteamiento de Idea de Proyecto y Análisis de Factibilidad.
* **Semana 02:** Modelo Canvas e Informe de Visión del Proyecto.
* **Semana 03:** Análisis y Diseño.
* **Semana 04:** Elaboración del Documento SRS.
* **Semana 07:** Avance del SAD y Documentación del Proyecto.

### UNIDAD 02
Espacio reservado para las actividades, documentos técnicos, laboratorios y evidencias que se desarrollarán progresivamente durante la segunda unidad[cite: 19].

### UNIDAD 03
Espacio preparado para los entregables, laboratorios, pruebas y evidencias correspondientes a la tercera unidad[cite: 19].
